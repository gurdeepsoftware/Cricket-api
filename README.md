# 🏏 Cricket API

An unofficial Cricket API client for fetching live cricket scores, fixtures, points tables, and match results.

## ✨ Features

- 🟢 Live Matches
- 📅 Fixtures
- 🏆 Results
- 📊 Points Table
- ⚡ JSON API
- 📱 Android App Support
